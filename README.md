# CV Mailer

A small Windows app that sends your CV to a list of email addresses, one separate email per person, and shows who replied and whether the answer looks good or bad.

Made by Haas7n.

## Download

Open the [latest release](https://github.com/swaybhco/CVMailer/releases/latest) and download `CVMailer.exe`. There is nothing to install, double click it to start.

If Windows shows a blue warning box the first time, click "More info", then "Run anyway".

The app updates itself from this page when a new version is published.
